## 📚 Laboratorio de Listas Enlazadas (Linked Lists)

Experimenta con la estructura de datos más flexible. A diferencia de las pilas y colas, las Listas **¡sí se recorren!** Domina la manipulación de punteros para insertar, quitar y buscar en cualquier posición.

### ✨ ¿Qué incluye?

* **Pizarra Interactiva Completa:** Simula operaciones de inserción y eliminación al **inicio**, al **final**, de forma **ordenada** o en una **posición** específica.
* **Búsqueda Dinámica:** Entiende cómo funciona la función `buscar()` para recorrer la lista por valor y devolver la dirección de memoria exacta (puntero) de un nodo.
* **Guía Visual de Punteros:** Domina el uso de `lista` (cabecera), `aux` (recorrido), y la dupla `ant` y `act` para puentear nodos en el medio de la estructura.
* **Modo Presentación Extendido:** 8 casos interactivos que explican paso a paso cada operación en memoria, incluyendo un repaso teórico de los **5 Tipos de Listas** (Simples, Dobles, Circulares, Circulares Dobles y Sublistas).
* **Código en Vivo y Apunte:** Genera tu `main()` dinámicamente y obtén todo el bloque de funciones de listas listas para copiar y pegar en tu IDE.
