Listas Enlazadas

Significado de cada puntero, pasaje de parámetros y recorridos
↑ lista = xxx1

Puntero Cabecera: apunta siempre al primer nodo de la lista. Nunca debemos usar lista directamente para recorrer porque perderíamos el inicio.

↑ aux

Puntero para recorrer: hacemos Nodo *aux = lista; y avanzamos con aux = aux->sgte; dentro de un while(aux != NULL).

↑ ant  |  ↑ act

Insertar o quitar en medio: act busca la posición y ant lo sigue un paso atrás (ant = act; act = act->sgte;) para poder puentear nodos.

Nodo * vs Nodo *&

Pasaje de parámetros: usamos Nodo *lista (valor) para mostrar/buscar y Nodo *&lista (referencia) para insertar o eliminar.

¡SÍ SE RECORREN!

Libertad total: a diferencia de pilas y colas, las listas sí se recorren y podés crear la función a medida que pida el parcial (buscar, ordenar, filtrar).

Resumen de Funciones de Listas

Operaciones de Inserción y Búsqueda

  1. Insertar Primero: nuevo->sgte = lista; lista = nuevo;
  2. Insertar al Final: recorro con while(aux->sgte != NULL) y conecto aux->sgte = nuevo;.
  3. Insertar Ordenado / en Posición: avanzo hasta el nodo anterior y conecto nuevo->sgte = aux->sgte; aux->sgte = nuevo;.
  4. Devolver puntero (buscar): recorro por valor (Nodo *lista) y retorno aux (dirección del nodo) o NULL.

Operaciones de Eliminación (Quitar)

  1. Quitar Primero: guardo aux = lista;, avanzo lista = aux->sgte; y libero delete aux;.
  2. Quitar al Final: avanzo con ant y aux hasta el último nodo, pongo ant->sgte = NULL; y delete aux;.
  3. Quitar en Posición / Medio: avanzo con ant y aux hasta pos, puenteo ant->sgte = aux->sgte; y libero delete aux;.
